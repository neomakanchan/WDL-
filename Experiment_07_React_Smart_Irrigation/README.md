# Experiment 07 — Component-Based React Application
## Smart Irrigation Advisory System

React practical adapted to the Smart Irrigation Advisory System case study. Demonstrates JSX, reusable functional components, props, useState(), event handling, and responsive CSS.

## Run
Install Node.js/npm, open this folder in VS Code, then run:

```bash
npm install
npm run dev
```
Open the local URL printed by Vite.

## Components
- `src/App.jsx`: dashboard, state and advisory decision logic
- `src/components/FarmSummary.jsx`: farm details component using props
- `src/components/IrrigationAdvisor.jsx`: input controls and event handling
- `src/components/AdviceResult.jsx`: advisory output component
- `src/App.css`: styling and responsive layout
- `src/main.jsx`: React entry point

Sample data and recommendations are for a laboratory demonstration only.

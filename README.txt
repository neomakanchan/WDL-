SMART IRRIGATION CSS EXPERIMENT 2
=================================

The HTML pages are based on Experiment 1 and the CSS requirements are taken from
Experiment 2.

TASK MAPPING
------------
Task 1 - Inline CSS
    index.html
    Header <header>, <h1> and <p> contain inline style attributes.

Task 2 - Internal CSS
    index.html
    Navigation styling is inside <style> in <head>.

Task 3 - External CSS
    style.css
    Linked from all relevant pages.

Task 4 - Sidebar
    sidebar.css
    Used in farm-info.html.

Task 5 - Card Layout / Box Model
    cards.css
    Used for workflow/farm cards in farm-info.html and plot-map.html.

Task 6 - Image Gallery
    gallery.css
    Used in gallery.html. Images have equal dimensions, borders,
    spacing, transition and transform: scale() hover effect.

Task 7 - Table Styling
    table.css
    Used in irrigation-table.html. Includes border-collapse,
    header styling, nth-child(even) zebra striping and centered text.

Task 8 - Registration Form
    form.css
    Used in registration.html. Includes input width/padding,
    :focus, :hover, border-radius, fieldset and legend styling.

Task 9 - Page Layout
    layout.css
    Uses Flexbox for sidebar-left/content-right layout and
    responsive stacking on smaller screens.

Task 10 - CSS Effects & Highlighting
    effects.css
    Uses an Offer box with background, larger font, text-shadow,
    box-shadow and @keyframes glow animation.

NOTE
----
The Experiment 2 PDF actually contains 10 CSS tasks, not 9.
All 10 have been included and adapted to the Smart Irrigation use case.
